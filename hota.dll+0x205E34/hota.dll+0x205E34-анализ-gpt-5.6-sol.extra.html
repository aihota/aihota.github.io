Визуализация вылета #

Две установленные ветви передают нулевой адрес назначения в _memset при ненулевой длине.

Roperator new
0NULL
M_memset, N > 0
Fзапись 0x00000000
A[AIMgr+24h] = 0
0NULL
M_memset, N > 0
Fзапись 0x00000000

Ресурсный путь и путь ИИ сходятся на одной инструкции rep stosb.

R Ресурсная ветвь: operator new возвращает нулевой адрес.
A Ветка ИИ: функция поиска возвращает ноль при нулевом поле [AIMgr+24h].
0 Нулевой адрес не проверяется потребителем.
M _memset получает ненулевую длину.
F Первая запись выполняется по адресу 0x00000000.
