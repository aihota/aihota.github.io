Визуализация вылета ¶

Непроверенный ID героя превращается в адрес структуры, после чего обработчик читает поле портрета по смещению +34h.

Pheroes_ids[slot]
Iпроверено только -1
Hbase + ID*0x492
F[ECX+34h]

ID без верхней границы выводит указатель за допустимый массив героев

P Запись из Player::heroes_ids является поставщиком ID.
I Код исключает 0xFFFFFFFF, но не ограничивает максимальный ID.
H Адрес героя равен GameMgr + 0x21620 + ID * 0x492.
F При ECX=0xBBA18300 чтение идёт по 0xBBA18334 и вызывает сбой.
