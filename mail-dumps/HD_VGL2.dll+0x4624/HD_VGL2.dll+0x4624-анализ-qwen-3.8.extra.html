Визуализация вылета #

Рабочий поток рендера делает два выделения подряд. Первое (мелкая структура) проверяется на NULL, второе (буфер кадра в несколько мегабайт) — нет: результат сразу разыменовывается. Когда malloc возвращает NULL, запись mov [eax],ecx при EAX=0 бьёт по адресу 0x00000000.

1 malloc 0x4C байта
✓ проверка test esi,esi; jz
2 malloc кадр W*H+0x18
✗ без проверки сразу [eax]
✗ запись [0] EAX=0, вылет

результат malloc проверяется (ветка отказа есть)
