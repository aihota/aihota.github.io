Визуализация вылета #

Отладочный распределитель HD-мода sub_1001A30 вызывает malloc(размер+4) и по результату идёт одним из двух путей. При успехе он ставит в заголовок блока служебную метку 0xF00DBEEF и возвращает указатель. При отказе (malloc вернул NULL) вместо возврата NULL выполняется запись mov [esi], esi по адресу, равному запрошенному размеру, — это и есть точка сбоя.

1 call _malloc malloc(размер+4) ECX = размер
2 test eax, eax EAX = результат развилка
A EAX != 0 [eax] = 0xF00DBEEF возврат блок+4
B EAX = 0 (все 13) mov [esi], esi адрес = размер → сбой
Путь B пройден во всех 13 дампах: EAX = 0, ESI = адрес сбоя = запрошенный размер.
1 Вход: ECX хранит размер выделения (например 0x100000 = 1 МиБ). Размер передают две функции работы со строковым буфером: конструктор sub_109A7E0 (начальный буфер 1 МиБ / 512 КиБ) и функция роста sub_109F260 (округление «использовано+1» вверх до 512 КиБ — источник крупных размеров).
2 malloc возвращает указатель в EAX; проверка test eax, eax выбирает путь — успех или отказ.
A Успех: в первые 4 байта блока пишется метка 0xF00DBEEF, возвращается указатель за ней. Штатный путь.
B Отказ: malloc вернул NULL (EAX = 0 во всех 13 дампах). Вместо возврата NULL выполняется mov [esi], esi — запись числа (размера) по адресу, равному размеру. Вызывающий код готов обработать NULL, но сбой случается раньше возврата.
