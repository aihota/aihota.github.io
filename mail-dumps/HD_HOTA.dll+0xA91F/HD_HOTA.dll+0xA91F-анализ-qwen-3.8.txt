Модель: Qwen 3.8

КРАТКОЕ РЕЗЮМЕ
--------------

Вылет происходит в функции HD_HOTA.dll (sub_100A810), которая обновляет панели портретов героев на карте приключений (HD.AdvMgr.ID15, HD.AdvMgr.ID20). Функция получает локального игрока через A0_GameMgr_GetMe_AsPlayer_sub_4CE670, берёт из его структуры индекс героя, умножает на размер структуры героя (0x492) и прибавляет базу массива героев (0x21620 от менеджера игры). В сетевой партии, где локальный игрок не определён (Me: ERROR), список героев в структуре игрока содержит мусор. Вычисленный указатель на героя оказывается в неотображённой памяти, и чтение байта по смещению +0x34 (индекс портрета) вызывает EXCEPTION_ACCESS_VIOLATION.

Семья из 31 лога на 7 адресах (версии 5.6 R24 — 5.7 R34) подтверждает: все вылеты — в сетевой игре с Me: ERROR, один механизм, одна цепочка вызовов. Дефект унаследован от SoD: оригинальная функция A0_AdvMgr_UpdateHeroPort_sub_403560 (h3hota.exe) содержит ту же логику и ту же недостающую проверку индекса героя.

8. Первопричина
---------------

Функция sub_100A810 (HD_HOTA.dll) зарегистрирована как перехватчик через sub_1034EC0 (DATA XREF: sub_1034EC0+3417). Обновляет панели HD.AdvMgr.ID15 и HD.AdvMgr.ID20 — портреты героев на карте приключений.

Получение локального игрока:

    .text:0100A814  mov     ecx, ds:699538h            ; A0_GameMgr_dword_699538
    .text:0100A81A  mov     eax, 4CE670h
    .text:0100A821  call    eax                        ; A0_GameMgr_GetMe_AsPlayer_sub_4CE670
    .text:0100A823  mov     edi, [ebp+arg_8]           ; индекс слота (0-7)
    .text:0100A826  mov     esi, eax                   ; указатель на структуру игрока

A0_GameMgr_GetMe_AsPlayer_sub_4CE670 (h3hota.exe) для сетевой игры (НЕ HotSeat) берёт A0_MeAtGameStart_dword_6995A4 БЕЗ проверки диапазона:

    .text:004CE6C6  mov     eax, dword ptr A0_MeAtGameStart_dword_6995A4
    .text:004CE6CB  lea     eax, [eax+eax*4]           ; x5
    .text:004CE6CF  lea     eax, [eax+eax*8]           ; x45
    .text:004CE6D2  lea     eax, [ecx+eax*8+20AD0h]    ; менеджер + id x 360 + 0x20AD0
    .text:004CE6D9  retn

Для HotSeat (режим 3) проверка диапазона ЕСТЬ (jl/jge на 0 и 8). Для сетевой игры — нет.

Вычисление указателя на героя:

    .text:0100A855  mov     eax, [esi+edi*4+8]         ; индекс героя из списка игрока
    .text:0100A85A  cmp     eax, 0FFFFFFFFh            ; проверка на -1
    .text:0100A85D  jz      loc_100AA5B                ; выход если -1
    .text:0100A876  imul    eax, 492h                  ; x размер структуры героя (1170 байт)
    .text:0100A882  add     eax, ds:41C6B5h            ; + 0x21620 (смещение массива героев)
    .text:0100A888  add     eax, ds:699538h            ; + указатель на менеджер игры
    .text:0100A88E  mov     [ebp+arg_8], eax           ; сохранить как указатель на героя

Значение [0x41C6B5] извлечено из середины инструкции lea в h3hota.exe:

    .text:0041C6B2  lea     esi, [eax+edx*2+21620h]

Байты по адресу 0x41C6B5: 20 16 02 00 = 0x00021620. Это смещение массива героев (hero_astr21620) в структуре менеджера игры.

Итого: указатель_на_героя = менеджер_игры + 0x21620 + индекс_героя x 0x492.

Чтение портрета и краш:

    .text:0100A910  push    offset aHotaHpsTbl         ; "HotA.HPS_tbl"
    .text:0100A915  call    sub_1002E90                ; поиск таблицы
    .text:0100A91A  mov     ecx, [ebp+arg_8]           ; указатель на героя
    .text:0100A91D  mov     eax, [eax]
    .text:0100A91F  movzx   ecx, byte ptr [ecx+34h]    ; КРАШ: индекс портрета
    .text:0100A923  push    dword ptr [eax+ecx*4]      ; элемент таблицы HPS
    .text:0100A926  mov     eax, 450170h
    .text:0100A92B  mov     ecx, esi
    .text:0100A92D  call    eax                        ; A0_DlgStaticPcx8_SetPcx_sub_450170

Функция 0x450170 в h3hota.exe — A0_DlgStaticPcx8_SetPcx_sub_450170: устанавливает изображение портрета на элемент интерфейса.

Механизм: в сетевой партии (Network Game = 1, режим НЕ HotSeat) функция GetMe_AsPlayer возвращает указатель на структуру игрока по значению A0_MeAtGameStart_dword_6995A4 без проверки. Когда локальный игрок не определён (Me: ERROR), структура игрока содержит некорректные данные — в частности, список героев (массив по смещению +8 от начала структуры игрока) заполнен мусором.

Sub_100A810 берёт из этого списка индекс героя, умножает на 0x492 и прибавляет базу массива героев. Мусорный индекс даёт указатель в неотображённую память. Чтение байта по смещению +0x34 (индекс портрета героя) вызывает нарушение доступа.

Проверка cmp eax, 0FFFFFFFFh (индекс не равен -1) не помогает: мусорный индекс не равен -1, но выходит далеко за пределы массива героев.

Наследование от SoD: оригинальная функция A0_AdvMgr_UpdateHeroPort_sub_403560 (h3hota.exe) содержит ту же логику и тот же дефект:

    .text:004035AF  mov     ecx, [eax+ecx*4+8]         ; индекс героя из player.heroes_ids
    .text:004035B3  cmp     ecx, 0FFFFFFFFh            ; проверка ТОЛЬКО на -1
    .text:004035DF  lea     ebx, [eax+edx*2+21620h]    ; game_mgr + index x 0x492 + 0x21620
    .text:004035FA  mov     al, [ebx+34h]              ; чтение [hero+34h] БЕЗ проверки указателя

HD-мод воспроизводит код движка, включая дефект.

Writer'ы A0_MeAtGameStart_dword_6995A4:

- 0x45B61F — кампания: A0_Me_Const_dword_6995A4 = v40 (индекс игрока)
- 0x4EF4F0 — fallback: A0_Me_Const_dword_6995A4 = 0
- 0x4EFBBB — сетевая инициализация: A0_Me_Const_dword_6995A4 = v83 (индекс локального игрока, с пометкой is_human_byteE2 = 1, is_on_this_computer_byteE1 = 1)

11. Воспроизведение вылета
--------------------------

Условие активации пути: сетевая партия (TCP/IP), в которой локальный игрок переходит в состояние ERROR (Me: ERROR). Это состояние фиксируется репортёром HD-мода, когда A0_MeAtGameStart_dword_6995A4 не указывает на корректного игрока.

Базовый сценарий:

- Запустить сетевую партию (TCP/IP, 2+ игрока)
- Довести локального игрока до состояния ERROR (потеря соединения, рассинхронизация, выход из партии в определённый момент)
- Наблюдать вылет при обновлении панелей карты приключений

Варьирование:

- День партии не влияет (наблюдались вылеты от дня 1 1 1 до 7 1 6)
- Graphics.Mode не влияет (наблюдались режимы 3 и 5; в функции нет ветвления по режиму)
- Карта не влияет (разные карты в логах семьи)

ВЫВОД
-----

Вылет HD_HOTA.dll+0xA91F — повреждение данных в памяти: функция HD-мода sub_100A810 (обновление портретов героев на панелях HD.AdvMgr.ID15/ID20 карты приключений) вычисляет указатель на структуру героя из данных игрока, полученных через A0_GameMgr_GetMe_AsPlayer_sub_4CE670. В сетевой партии с состоянием Me: ERROR список героев в структуре игрока содержит мусор. Мусорный индекс, умноженный на размер структуры героя (0x492) и сложенный с базой массива героев (менеджер_игры + 0x21620), даёт указатель в неотображённую память. Чтение индекса портрета по смещению +0x34 вызывает нарушение доступа.

Семья из 31 лога на 7 адресах (версии 5.6 R24 — 5.7 R34) подтверждает: все вылеты в сетевой игре с Me: ERROR, один механизм, одна цепочка вызовов. Виновный код — в HD_HOTA.dll, но дефект унаследован от SoD: оригинальная A0_AdvMgr_UpdateHeroPort_sub_403560 (h3hota.exe) содержит ту же логику и ту же недостающую проверку индекса героя.

Полезность лога СРЕДНЯЯ: падающая функция корректна для корректных данных, корень — в состоянии игры (Me: ERROR в сетевой партии), при котором структура игрока содержит мусор. Фикс — защитная проверка индекса героя или состояния игрока в sub_100A810.
