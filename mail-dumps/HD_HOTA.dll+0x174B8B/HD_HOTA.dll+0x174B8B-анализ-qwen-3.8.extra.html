Визуализация вылета

HD-мод выбирает случайного активного игрока: считает количество игроков с ненулевым сетевым идентификатором (net_id), затем делит случайное число на это количество. Когда активных игроков нет, делитель равен нулю.

1 Массив игроков 8 слотов, поле net_id
2 Подсчёт активных sub_11744F0: net_id ≠ 0
3 Делитель = 0 var_30 = число активных
4 rand() ÷ var_30 idiv [ebp+var_30]
5 Вылет INT_DIVIDE_BY_ZERO
Массив игроков движка (player_astr20AD0): HD-мод читает поле net_id каждого из 8 слотов.
Функция sub_11744F0 ставит флаг «активен» для каждого игрока с ненулевым net_id.
В начале сетевой партии (день 1 1 1) все net_id нулевые → активных игроков 0 → делитель var_30 = 0.
Деление rand() на 0 без проверки «число игроков > 0» → EXCEPTION_INT_DIVIDE_BY_ZERO.

Поток данных: массив игроков → подсчёт активных → нулевой делитель → деление → вылет.
