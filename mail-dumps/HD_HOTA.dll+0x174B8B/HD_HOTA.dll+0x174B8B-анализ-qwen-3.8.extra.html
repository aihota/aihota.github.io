Визуализация вылета

HD-мод строит из массива игроков связный список активных (с ненулевым сетевым идентификатором net_id), считает их количество и делит на него случайное число, чтобы обойти список и выбрать случайного игрока. Когда активных игроков нет, делитель равен нулю.

1 Массив игроков 8 слотов · поле net_id
2 sub_11744F0 список активных · next=record+3
3 Делитель = 0 var_30 = число активных
4 rand() % var_30 idiv [ebp+var_30]
5 Вылет INT_DIVIDE_BY_ZERO
Массив игроков движка (player_astr20AD0): HD-мод читает net_id каждого из 8 слотов.
sub_11744F0 ставит флаг «активен» (net_id ≠ 0) и связывает активных игроков указателями «следующий» (record+3).
В начале сетевой партии (день 1 1 1) все net_id нулевые → активных игроков 0 → делитель var_30 = 0.
Деление rand() на 0 без проверки «число игроков > 0» → вылет. При var_30 > 0 остаток rand % var_30 задал бы число шагов обхода связного списка для выбора случайного игрока.

Поток: массив игроков → связный список активных → нулевой делитель → деление → вылет.
