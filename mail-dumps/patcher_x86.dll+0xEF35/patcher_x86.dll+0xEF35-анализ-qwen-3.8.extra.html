Визуализация вылета

Патчер HD-мода хранит для каждого хука «ячейку» со счётчиком глубины вложенных вызовов. Вход в контекст наращивает счётчик, выход — уменьшает. Пока счётчик не опускается ниже нуля, всё штатно. Сбой начинается, когда выходов оказывается на один больше, чем входов: счётчик из нуля уходит в минус один, отрицательный уровень превращается в индекс массива, а указатель на этот массив у ячейки ещё нулевой — чтение по нулю обрушивает процесс.

1ВХОДсчётчик 0 → 1
2ВЫХОДсчётчик 1 → 0
3ИТОГвозврат значения
Норма: входов и выходов поровну, счётчик возвращается в ноль
1ВХОДсчётчик 0 → 1
2ВЫХОДсчётчик 1 → 0
3ЛИШНИЙ ВЫХОДсчётчик 0 → −1
4ИНДЕКСуровень −2 (ECX = −6)
5БУФЕР ЯЧЕЙКИуказатель = NULL
Сбой: лишний выход уводит счётчик в минус; отрицательный индекс читает никогда не выделенный буфер — адрес сбоя 0 + (−6)×8 = 0xFFFFFFD0
✓Шаги 1–2 (норма) — функция входа sub_1000F020 увеличивает счётчик (inc), функция выхода sub_1000EE60 уменьшает (dec); на нуле возвращается сохранённое значение.
3Лишний выход — dec на счётчике 0 даёт −1; ненулевое значение уводит код на «путь вложенности» вместо штатного возврата.
4Отрицательный индекс — уровень = счётчик − 1 = −2; в хвосте функции он умножается на три (lea ecx, [eax+eax*2]) и становится индексом ECX = −6.
5Нулевой буфер — массив ячейки (поле +0x1C) выделяется только при росте глубины; для этой ячейки он не создавался, mov eax, [ebx+1Ch] загружает 0, и mov eax, [eax+ecx*8] читает память по нулю.
