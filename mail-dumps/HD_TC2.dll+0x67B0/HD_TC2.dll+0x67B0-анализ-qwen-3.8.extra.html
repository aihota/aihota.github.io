Визуализация вылета

Блиттер True Color читает поля спрайта Pcx8 по порядку. Шаг строки и таблица палитры читаются успешно — значит, сам объект-спрайт жив. Сбой происходит на третьем чтении: буфер пикселей источника невалиден, инструкция mov cl,[edx] разыменовывает его без проверки.

1this+0x2Cшаг строкичитается
2this+0x24Cтаблица палитрычитается
3this+0x30буфер пикселейСБОЙ
Порядок чтений полей спрайта: первые два проходят, третье (буфер пикселей) падает.

Три проявления одного дефекта — буфер пикселей невалиден по-разному, но механизм общий (разыменование источника без проверки):

Aисточник = нуль77 дамповthis+0x30 == 0
Bвисячий указатель24 дампаадрес освобождён
Cвыход за буфер13 дамповширина больше буфера
1Поля спрайта, которые читаются до сбоя: объект размещён и жив, таблица палитры на месте.
3Буфер пикселей (this+0x30) — единственное битое поле; адрес сбоя совпадает с EDX во всех 114 дампах.
AУказатель буфера нулевой: буфер не выделен (отказ operator new, 56 дампов) либо память уже переиспользована (use-after-free, 21 дамп — в поле ширины видно чужое содержимое «CmNumWHD.pcx»/«.bmp»).
BБуфер освобождён (висячий указатель) — чтение незамапленной памяти на первом пикселе.
CБуфер короче объявленной ширины — строка началась годно, ширина увела за границу страницы.
iКорень — жизненный цикл Pcx8 в движке SoD (h3hota.exe): функция чтения оставляет нулевой буфер при отказе operator new, создатель не проверяет код возврата; HD-мод воспроизводит дефект. Блиттер HD_TC2 — исправный порт, место проявления.
