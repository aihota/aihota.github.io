Визуализация вылета

Путь сбоя: обработчик городского экрана HD-мода лениво создаёт объект-сетку диалога найма. Функция создания возвращает NULL (отказ operator new), а конструктор возврат не проверяет и пишет таблицу виртуальных методов по нулевому указателю.

1 sub_1015780 обработчик города
2 sub_11B30D0 ленивое создание
3 sub_11B9210 конструктор
4 sub_11B6EC0 создание → NULL
5 mov [eax], … КРАШ: EAX = 0
Цепочка вызовов и поток нулевого указателя (R33; в RC4/RC10 функции смещены по образу)
1HD-мод перехватывает сообщения городского экрана (sub_1015780, зарегистрирован инициализатором sub_1034EC0).
2sub_11B30D0 создаёт объекты-сетки при первом открытии диалога найма; this = глобальный менеджер dword_120BD9C (EDI = 0x0839BD9C).
3Конструктор sub_11B9210 зовёт функцию создания sub_11B6EC0 и ждёт указатель в EAX.
4Функция создания корректно возвращает NULL при отказе operator new (и освобождает заголовок) — контракт поставщика соблюдён.
5Конструктор не проверяет возврат (test eax,eax отсутствует) и пишет таблицу виртуальных методов off_120BD7C по EAX = 0 → запись по нулю.
