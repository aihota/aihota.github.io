Визуализация вылета #

При ранней инициализации DirectDraw игра вызывает SetClipper первичной поверхности (флаг 698808 ещё не загружен, BSS=0 — оконная ветка инициализации). К этому моменту первичная поверхность не создана: IDirectDraw::CreateSurface завершился неудачей (внешняя причина — DirectDraw/видеодрайвер), поэтому dword_1004C9EC = 0. Перехватчик SetClipper HD-мода (sub_100189A0) разыменовывает нулевой указатель. Первичная поверхность при этом всегда запрашивается с DDSCAPS_PRIMARYSURFACE (полноэкранный путь создания) — дело именно в неудаче создания, а не в оконном пути. Вылет подтверждён 11 логами в 8 версиях HD-мода.

1 Ранняя инициализация флаг 698808 ещё не загружен BSS=0, оконная ветка игры
2 h3hota.exe игра вызывает SetClipper первичной поверхности
3 CreateSurface создание НЕ удалось dword_1004C9EC = 0
4 sub_100189A0 mov ecx,[eax] при EAX = 0 краш (0x00000000)

Механизм краша: игра вызывает SetClipper (шаги 1-2), но поверхность не создана — CreateSurface не удался (шаг 3), перехватчик HD-мода разыменовывает нуль (шаг 4).

W Windows (краш) CreateSurface не удался dword_1004C9EC = 0
L Wine (нет краша) CreateSurface успешен dword_1004C9EC = obj
= Различие в успешности создания внешняя причина

Различие между Windows (краш) и Wine (нет краша) — в успешности создания поверхности DirectDraw (проверено winedbg: под Wine dword_1004C9EC/D8/F0 созданы). Причина неудачи на Windows — внешняя (DirectDraw/видеодрайвер), код ошибки в краш-лог не попадает.

1 При ранней инициализации флаг полноэкранности 698808 ещё не загружен из реестра (BSS=0) — игра идёт по оконной ветке A0_DirectDrawInit (подтверждено winedbg: A0_DirectDrawInit срабатывает раньше записи настройки по 0x4EDD22)
2 h3hota.exe вызывает SetClipper первичной поверхности (vtable +0x70, строка 00601C5D) — перехватывается HD-модом (sub_100189A0)
3 IDirectDraw::CreateSurface ([ecx+18h] в sub_100182C0) завершился неудачей — dword_1004C9EC остался 0. Первичная поверхность всегда с DDSCAPS_PRIMARYSURFACE (sub_600BB0(800,600,1) → ddsCaps=0x200), так что оконный путь создания ни при чём
4 _HD3_.dll:sub_100189A0 — перехватчик SetClipper; mov ecx, [eax] при EAX = 0 (dword_1004C9EC не создан) → чтение по адресу 0x00000000
W Windows: создание поверхности не удалось (внешняя причина) → dword_1004C9EC = 0 → краш (11 логов, 8 версий HD-мода, Graphics.Mode=3)
L Wine: создание поверхности успешно (dword_1004C9EC = 0x411b778, dword_1004C9D8 = 0x3f1d188, dword_1004C9F0 = 0x47cf348) → краш не воспроизводится
