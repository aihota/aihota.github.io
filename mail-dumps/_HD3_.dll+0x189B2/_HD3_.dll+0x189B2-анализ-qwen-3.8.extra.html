Визуализация вылета #

Корень дефекта — порядок инициализации внутри sub_100182C0: обёртка поверхности (с перехватчиками) публикуется РАНЬШЕ создания внутреннего объекта, а в оконном пути объект не создаётся вовсе.

1 sub_100182C0+3C Обёртка опубликована перехватчики активны
! ОКНО СБОЯ Перехватчики активны, но dword_1004C9EC = 0
2 sub_100182C0+199 Создание объекта ТОЛЬКО полный экран
3 Штатная работа Перехватчики используют валидный объект

Полноэкранный путь ([arg_0+68h] & 0x200 установлен): обёртка публикуется на +0x3C, объект создаётся на +0x199 — между ними окно с нулевым глобалом.

1 sub_100182C0+3C Обёртка опубликована перехватчики активны
! Ветвление Флаг [arg_0+68h] & 0x200 сброшен
X Оконный путь Объект НЕ создаётся глобал = 0 всегда
D sub_100189A0 mov ecx,[eax] при EAX = 0 детерминированный краш

Оконный путь (loc_100184B7): объект dword_1004C9EC не создаётся вовсе, глобал остаётся нулевым — первый же вызов перехватчика sub_100189A0 падает.

A hota.dll sub_100D1B10
B _HD3_.dll sub_10010CE0 диспетчер (SEH)
C h3hota.exe A0_DirectDraw Init_sub_601AB0
D _HD3_.dll sub_100189A0 mov ecx,[eax]

Цепочка вызовов: hota.dll запускает инициализацию через диспетчер HD-мода (B), который вызывает оригинальную функцию игры (C). Игровой код вызывает метод vtable поверхности, перехваченный HD-модом, что приводит к перехватчику (D) с EAX = 0.

1 Публикация обёртки поверхности (mov [esi], edi на sub_100182C0+3C); таблица перехватчиков содержит sub_100189A0 (слот +0x74)
! Окно сбоя (полноэкранный путь) или ветвление с сброшенным флагом (оконный путь): глобал dword_1004C9EC равен нулю
2 Создание объекта dword_1004C9EC (vtable-вызов [ecx+18h], выходной параметр) — только в полноэкранном пути
3 Штатная работа: глобал валиден, vtable-вызов проходит успешно
X Оконный путь (loc_100184B7): объект не создаётся, глобал остаётся нулевым
