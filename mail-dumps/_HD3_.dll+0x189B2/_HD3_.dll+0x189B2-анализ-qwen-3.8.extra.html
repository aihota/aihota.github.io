Визуализация вылета #

Окно уязвимости при инициализации: перехватчики HD-мода регистрируются РАНЬШЕ создания внутренних объектов. Вызов из игрового кода в этом окне попадает в callback с нулевым глобальным указателем.

1 sub_100181A0 Таблица перехватчиков слоты +0x0C..+0x84
! ОКНО СБОЯ Перехватчики активны, но dword_1004C9EC = 0
2 sub_100182C0+199 Создание объектов dword_1004C9EC = obj
3 Штатная работа Callback'и используют валидный объект

Инициализация sub_100182C0: сначала регистрация перехватчиков (шаг 1), затем создание объектов (шаг 2). Вызов из A0_DirectDrawInit в окне между ними разыменовывает нулевой указатель.

A hota.dll sub_100D1B10
B _HD3_.dll sub_10010CE0 диспетчер (SEH)
C h3hota.exe A0_DirectDraw Init_sub_601AB0
D _HD3_.dll sub_100189A0 mov ecx,[eax]

Цепочка вызовов: hota.dll запускает инициализацию через диспетчер HD-мода (B), который вызывает оригинальную функцию игры (C). Игровой код вызывает метод vtable поверхности, перехваченный HD-модом, что приводит к callback'у (D) с EAX = 0.

1 Регистрация перехватчиков (таблица sub_100181A0, слот +0x74 = sub_100189A0)
! Окно сбоя: перехватчики активны, глобал dword_1004C9EC ещё равен нулю
2 Создание объектов поверхности (vtable-вызов [ecx+18h], выходной параметр dword_1004C9EC)
3 Штатная работа: глобал валиден, vtable-вызов [ecx+70h] проходит успешно
A hota.dll:sub_100D1B10 — запуск инициализации графики
B _HD3_.dll:sub_10010CE0 — главный диспетчер перехватов (обёрнут в SEH)
C h3hota.exe:A0_DirectDrawInit_sub_601AB0 — инициализация DirectDraw (DirectDrawCreate, SetCooperativeLevel, SetDisplayMode)
D _HD3_.dll:sub_100189A0 — точка краша: mov ecx, [eax] при EAX = 0 (глобал не создан)
