Визуализация сбоя ¶

Сплошная цепочка показывает подтверждённые операции. Пунктирный блок отделяет неизвестное происхождение нулевого состояния.

1 Подтверждённая цепочка чтения
C клеткаMapCell+4
S элементAdvMgr+0x504+4*n
0 DEF0x00000000
F вылетчтение 0x00000020
2 Граница имеющихся данных
? источникне сохранён в минидампе

Нулевой элемент доказан; его первый производитель неизвестен.

C C — байт типа земли читается из клетки карты.
S S — адрес элемента вычисляется по сохранённому смещению.
0 0 — выбранный элемент содержит нулевой указатель DEF.
F F — чтение поля +0x20 вызывает исключение.
? ? — фактический индекс и источник NULL не захвачены.
